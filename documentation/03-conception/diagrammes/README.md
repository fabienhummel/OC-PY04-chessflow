# Diagrammes de ChessFlow

Ce dossier contient les diagrammes de conception de ChessFlow.

## Organisation

- `sources/` : sources PlantUML faisant foi ;
- `exports/` : rendus SVG générés depuis les sources.

## Diagrammes

- `cas-utilisation-chessflow` : interactions entre l'organisateur et l'application ;
- `classes-metier-chessflow` : modèle objet `Player`, `Tournament`, `Round` et `Match`.

Toute modification d'un diagramme doit être réalisée dans le fichier `.puml`, puis le SVG correspondant doit être régénéré.
